## 1. 概述

本文档基于 [proposal.md](./proposal.md) 的需求，完成 danci-h5 的技术设计，覆盖：

- **数据库**：现有 `words` / `books` 表的对接，认证用户表，以及新增的「学习进度」表；
- **后端**：NextAuth 认证、API 路由、数据访问层（Drizzle）；
- **前端**：页面路由、组件划分、移动端适配、学习/详情页实现要点；
- **关键流程**：登录、继续学习、进度保存的时序设计。

```
│  ├─ Server Components：直接读库渲染（RSC）                │
│  ├─ API Routes：/api/books、/api/books/[id]/words、      │
│  │              /api/progress、/api/auth/[...nextauth]  │
│  ├─ Server Actions：登录 / 注册 / 退出登录                 │
│  └─ NextAuth：Credentials 认证 + JWT Session             │
└───────────────────────┬─────────────────────────────────┘
                        │ drizzle-orm + postgres-js
┌───────────────────────▼─────────────────────────────────┐
│         PostgreSQL（Supabase 云端数据库）                  │
│  books（单词书） / words（单词） / User（用户）            │
│  learning_progress（学习进度，新增）                      │

```

**架构决策：**
| 决策 | 说明 |
| --- | --- |
| 服务端渲染为主 | 首页/我的等页面用 Server Component 直接查库，减少接口调用 |
| 认证放服务端 | 登录/注册用 Server Actions 调用现有 `signIn` / `createUser` |
| API 路由为辅 | 供客户端组件使用（学习页切词保存进度、弹窗登录后的会话刷新等） |
| 进度写库走 API | `POST /api/progress` 由客户端在「下一个」时调用，实时保存 |

## 4. 数据库设计

### 4.1 设计约定

- 生产库列名存在历史差异：`words` 表使用**带引号驼峰**列（`"wordRank"` 等），`books` 表使用 **snake_case**（`word_count` 等）。Drizzle schema 中以 `columns` 配置与物理列一一对应，代码侧可用驼峰。
- 新增表统一使用 **snake_case** 物理列名 + `_id` 外键后缀。
- 主键统一 `bigint generated by default as identity`（沿用 `words` 风格）。
- 所有表记录 `created_at / updated_at`（仅业务表）。

### 4.2 现有表：words（单词数据表，只读）

```sql
create table public.words (
  id bigint generated by default as identity not null,
  "wordRank" integer null,
  "headWord" text null,
  content json null,
  "bookId" text null,
  constraint words_pkey primary key (id)
) TABLESPACE pg_default;
```

| 列 | 类型 | 说明 |
| --- | --- | --- |
| `id` | bigint identity PK | 主键 |
| `wordRank` | integer | 单词在书内的序号（学习进度以此为锚点） |
| `headWord` | text | 单词本身（如 `ruler`） |
| `content` | json | 完整词条内容（例句/音标/短语/同近/同根/记忆法，结构见 4.5） |
| `bookId` | text | 所属单词书 `book_id` |

**建议补充索引：** `create index idx_words_book_rank on public.words ("bookId", "wordRank");`（按书查询 + 排序）

### 4.3 现有表：books（单词书表）

```sql
create table public.books (
  id uuid not null default gen_random_uuid (),
  title text not null,
  word_count integer not null default 0,
  cover_url text null,
  book_id text not null,
  tags text null,
  created_at timestamp with time zone not null default now(),
  updated_at timestamp with time zone not null default now(),
  constraint books_pkey primary key (id),
  constraint books_book_id_unique unique (book_id)
) TABLESPACE pg_default;
```

| 列 | 类型 | 说明 |
| --- | --- | --- |
| `id` | uuid PK | 主键 |
| `title` | text | 书名（如「三年级上」） |
| `word_count` | integer | 单词总数 |
| `cover_url` | text | 封面图 |
| `book_id` | text unique | 业务标识，`words.bookId` 关联此列 |
| `tags` | text | 标签 |
| `created_at / updated_at` | timestamptz | 时间戳 |

关联：`words."bookId" → books.book_id`（无物理外键，靠业务字段关联）。

### 4.4 现有表：User（认证用户表）

由 h5 应用启动时自动创建（`app/db.ts` 的 `ensureTableExists`）：

```sql
create table if not exists public."User" (
  id serial primary key,
  email varchar(64),
  password varchar(64)
);
```

| 列 | 类型 | 说明 |
| --- | --- | --- |
| `id` | serial PK | 用户 ID（学习进度表的 `user_id` 引用它） |
| `email` | varchar(64) | 登录邮箱 |
| `password` | varchar(64) | bcrypt 哈希 |

> 注意：表名带引号为 `"User"`（保留字冲突），drizzle 映射时使用 `pgTable('User', ...)`。

### 4.5 新增表：learning_progress（学习进度表）

用于：首页「最近学习」、我的页进度条、学习页起始位置（`last_word_rank + 1`）。

```sql
create table public.learning_progress (
  id bigint generated by default as identity not null,
  user_id integer not null,
  book_id text not null,
  learned_count integer not null default 0,
  last_word_rank integer not null default 0,
  updated_at timestamp with time zone not null default now(),
  constraint learning_progress_pkey primary key (id),
  constraint learning_progress_user_book_unique unique (user_id, book_id),
  constraint learning_progress_user_fk foreign key (user_id)
    references public."User" (id) on delete cascade,
  constraint learning_progress_book_fk foreign key (book_id)
    references public.books (book_id) on delete cascade
) TABLESPACE pg_default;

create index idx_progress_user on public.learning_progress (user_id, updated_at desc);
```

| 列 | 类型 | 说明 |
| --- | --- | --- |
| `id` | bigint identity PK | 主键 |
| `user_id` | integer | 用户 ID（FK → `"User".id`，级联删除） |
| `book_id` | text | 单词书（FK → `books.book_id`，级联删除） |
| `learned_count` | integer | 该书已学单词数（顺序学习时 = `last_word_rank`） |
| `last_word_rank` | integer | 最近学到的 `wordRank`，下次学习从 `+1` 开始 |
| `updated_at` | timestamptz | 最近学习时间（「最近学习」模块按此排序取最新） |

**约束与索引：**
- `unique(user_id, book_id)`：一人一书一条记录，写库用「存在则更新」；
- `idx_progress_user (user_id, updated_at desc)`：首页「最近学习」快速取最新一条。

**RLS 建议（Supabase）：**
- `learning_progress` 为**用户私有数据**，开启行级安全：`policy for user_progress on learning_progress using (user_id = auth.uid())`；
- `words` / `books` 为公共数据，不开启 RLS。

### 4.6 单词 JSON `content` 结构（供渲染层设计）

```jsonc
{
  "wordRank": 1,
  "headWord": "ruler",
  "bookId": "PEPXiaoXue3_1",
  "content": {
    "word": {
      "wordHead": "ruler",
      "wordId": "PEPXiaoXue3_1_1",
      "content": {
        "sentence": { "sentences": [{ "sContent": "...", "sCn": "..." }], "desc": "例句" },
        "usphone": "'rulɚ",
        "ukphone": "'ruːlə",
        "ukspeech": "ruler&type=1",
        "usspeech": "ruler&type=2",
        "trans": [{ "tranCn": "尺子", "descCn": "中释", "descOther": "英释", "tranOther": "..." }],
        "phrase": { "phrases": [{ "pContent": "...", "pCn": "..." }], "desc": "短语" },
        "syno": { "synos": [{ "pos": "n", "tran": "...", "hwds": [{ "w": "governor" }] }], "desc": "同近" },
        "relWord": { "rels": [{ "pos": "adj", "words": [{ "hwd": "ruling", "tran": "..." }] }], "desc": "同根" },
        "remMethod": { "val": "记忆方法文案", "desc": "记忆" }
      }
    }
  }
}
```

**渲染取值路径：**
- 卡片：`headWord` + `ukphone|usphone` + `content.word.content.trans[0].tranCn` + `sentence.sentences[0]`；
- 详情：`content.word.content` 下的全部区块（见 §6.5.4）；
- 发音：`ukspeech` / `usspeech`（值为 `ruler&type=1`），音频 URL = `NEXT_PUBLIC_AUDIO_BASE + speech`。

### 4.7 Drizzle Schema（TypeScript 实现参考）

新增 `db/schema.ts`（h5 应用）：

```ts
import { pgTable, bigint, serial, text, integer, json, timestamp, uniqueIndex, index } from 'drizzle-orm/pg-core';

// 认证用户（现有）
export const users = pgTable('User', {
  id: serial('id').primaryKey(),
  email: varchar('email', { length: 64 }),
  password: varchar('password', { length: 64 }),
});

// 单词（现有，只读）
export const words = pgTable('words', {
  id: bigint('id', { mode: 'number' }).primaryKey(),
  wordRank: integer('wordRank'),
  headWord: text('headWord'),
  content: json('content'),
  bookId: text('bookId'),
}, (t) => [index('idx_words_book_rank').on(t.bookId, t.wordRank)]);

// 单词书（现有，只读）
export const books = pgTable('books', {
  id: text('id'),
  title: text('title').notNull(),
  wordCount: integer('word_count').notNull().default(0),
  coverUrl: text('cover_url'),
  bookId: text('book_id').notNull().unique(),
  tags: text('tags'),
  createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
  updatedAt: timestamp('updated_at', { withTimezone: true }).notNull().defaultNow(),
});

// 学习进度（新增）
export const learningProgress = pgTable('learning_progress', {
  id: bigint('id', { mode: 'number' }).generatedByDefaultAsIdentity().primaryKey(),
  userId: integer('user_id').notNull(),
  bookId: text('book_id').notNull(),
  learnedCount: integer('learned_count').notNull().default(0),
  lastWordRank: integer('last_word_rank').notNull().default(0),
  updatedAt: timestamp('updated_at', { withTimezone: true }).notNull().defaultNow(),
}, (t) => [
  uniqueIndex('learning_progress_user_book_unique').on(t.userId, t.bookId),
  index('idx_progress_user').on(t.userId, t.updatedAt),
]);
```

> 迁移方式：沿用 danci-admin 的 `drizzle-kit generate` / `migrate` 流程（见根 README）。

## 5. 后端设计

### 5.1 认证设计（NextAuth）

复用模板现有实现，仅调整页面行为：

- `app/auth.ts`：Credentials Provider，`authorize` 中 `getUser(email)` → `compare(password)`；
- `app/auth.config.ts`：`authorized` 回调新增 H5 规则：
  - `/books/*`、`/words/*`（学习页/详情页）：未登录返回 `false` → 重定向到 `/?login=1`（首页弹出登录弹窗）；
  - 其余页面放行；
- `middleware.ts` matcher 保持 `/((?!api|_next/static|_next/image|.*\\.png$).*)`。

**会话策略：** JWT（默认）。`User.id` 需在 `session` 回调中注入，供学习进度表 `user_id` 使用：

```ts
callbacks: {
  session({ session, token }) {
    session.user.id = token.sub; // 用于写 learning_progress
    return session;
  },
}
```

### 5.2 API 接口定义

| 方法 | 路径 | 鉴权 | 请求 | 响应 |
| --- | --- | --- | --- | --- |
| GET | `/api/books` | 无 | - | `{ books: [{ id, title, wordCount, coverUrl, bookId, tags }] }` |
| GET | `/api/books/[bookId]/words` | 无 | - | `{ book: { title, wordCount }, words: [{ wordRank, headWord, content }] }`（按 wordRank 升序） |
| GET | `/api/progress` | 登录 | - | `{ progress: [{ bookId, learnedCount, lastWordRank, updatedAt }] }` |
| POST | `/api/progress` | 登录 | `{ bookId, lastWordRank }` | `{ progress: { ... } }`（upsert） |
| GET/POST | `/api/auth/[...nextauth]` | - | - | NextAuth 标准端点 |

**接口实现要点：**

- `/api/books/[bookId]/words`：`db.select().from(words).where(eq(words.bookId, bookId)).orderBy(words.wordRank)`，一次返回全部（每本 ≤ 200 词）；
- `POST /api/progress`：先 `getUser` 态校验（`auth()`），再按 `(userId, bookId)` upsert：

```ts
const { bookId, lastWordRank } = await request.json();
await db.insert(learningProgress).values({
  userId, bookId, learnedCount: lastWordRank, lastWordRank,
}).onConflictDoUpdate({
  target: [learningProgress.userId, learningProgress.bookId],
  set: { learnedCount: lastWordRank, lastWordRank, updatedAt: new Date() },
});
```

### 5.3 数据访问层（复用与扩展）

- `app/db.ts`：保留现有 `getUser` / `createUser` / `ensureTableExists`（User 表自建逻辑），新增：
  - `getBooks()`、`getWordsByBook(bookId)`、`getProgress(userId)`、`upsertProgress(...)`；
- 连接：`postgres(process.env.POSTGRES_URL + '?sslmode=require')`（现有），同一连接即可读 `words` / `books`（同库）。

### 6.4 状态与数据获取

| 场景 | 方式 |
| --- | --- |
| 首页（登录态、最近学习、单词书） | Server Component 直查：`auth()` + `getProgress()` + `getBooks()` |
| 我的页 | Server Component 直查：`auth()` + `getProgress()` |
| 学习页 | Server Component 预取单词列表传入 Client，`useState` 管理当前索引 |

### 6.5 关键页面实现要点

#### 6.5.1 首页（`(tabs)/page.tsx`）

```
const session = await auth();
const isLoggedIn = !!session?.user;
const progress = isLoggedIn ? await getProgress(session.user.id) : [];
const recent = progress.at(-1);              // 按 updated_at 最新
const books = await getBooks();
```
- 已登录且 `recent` 存在 → 渲染 `<RecentLearning />`；
- 未登录：单词书卡片 onClick → `router.push('/me?login=1')`（切换到我的 Tab 并弹窗）。

#### 6.5.2 我的页（`(tabs)/me/page.tsx`）

- 未登录：占位 + 「点击登录 / 注册」按钮（`setLoginPopup(true)`）；
- 已登录：邮箱（`session.user.email`）、每本书进度（`progress` join `books`）、累计已学数、退出按钮（Server Action `signOut({ redirectTo: '/me' })`）。

#### 6.5.3 登录/注册弹窗（`login-popup.tsx`）

- 两个 Tab：登录 / 注册，共用表单字段；
- 登录：`app/actions.ts` 的 `loginAction(formData)` → `signIn('credentials', { email, password, redirect: false })`，成功后 `router.refresh()`；
- 注册：`registerAction(formData)` → `getUser` 查重 → `createUser` → `signIn` 自动登录；
- 错误统一显示在弹窗内（`useState<string>`）。

#### 6.5.4 学习页（`books/[bookId]/page.tsx`）

- 起始索引：`(lastWordRank ?? 0)`（无进度从第 1 个开始）；
- 卡片渲染 `word-card`：单词、音标、`tranCn`、例句 `sentences[0]`；
- 「下一个」：`setIndex(i+1)` + `POST /api/progress { bookId, lastWordRank: 新词 wordRank }`；
- 卡片点击 → `router.push(\`/words/${bookId}/${rank}\`)`；
- 学完提示：`index >= words.length` 显示「本书已学完」。

#### 6.5.5 详情页（`words/[bookId]/[rank]/page.tsx`）

- 由 `bookId + rank` 查 `words` 表单条，渲染 `content.word.content` 各区块（例句/短语/同近/同根/记忆法，缺省区块自动隐藏）；
- 发音：`<audio>` + `<button onClick={play}>`，`src = \`${NEXT_PUBLIC_AUDIO_BASE}${speech}\``；
- 顶部「返回」`router.back()`。

## 7. 关键业务流程

### 7.1 登录流程

```
用户点击登录（首页点书 / 我的页按钮）
  → 切换到 /me?login=1 → LoginPopup 打开
  → 提交表单 → loginAction（Server Action）
     → NextAuth signIn('credentials') → authorize: getUser + compare
     → 成功：写 JWT cookie → router.refresh() → 关闭弹窗
     → 失败：弹窗内提示「邮箱或密码错误」
```

### 7.2 继续学习流程

```
首页（已登录）
  → 最近学习卡片「继续学习」
  → /books/[bookId]（Server Component）
     → 查 words（按 wordRank 升序）+ learning_progress
     → 起始索引 = lastWordRank + 1
  → 点击「下一个」
     → 前端切换卡片
     → POST /api/progress { bookId, lastWordRank }（异步，防抖）
  → 卡片点击 → /words/[bookId]/[rank] 详情页
```

### 7.3 未登录学习流程

```
首页点击单词书（未登录）
  → 切换到 /me?login=1 → 弹窗
  → 登录成功 → 回到首页 → 再次点击单词书 → 进入学习页（第 1 词）
```

## 9. 性能与安全

**性能**
- 单词书 ≤ 200 词，接口一次返回，学习页切词零网络请求；
- 首页/我的使用 RSC 服务端渲染，无客户端瀑布请求；
- `learning_progress` 索引覆盖「最近学习」与进度查询。

**安全**
- 密码 bcrypt 哈希，明文不落库；
- `learning_progress` 接口强制 `auth()` 校验，`user_id` 取自会话而非请求体（防止越权）；
- 建议开启 Supabase RLS（见 §4.5）。

## 10. 风险与注意事项

| # | 风险/注意 | 应对 |
| --- | --- | --- |
| 1 | `words` 驼峰列名与 `books` snake_case 不一致 | Drizzle columns 显式映射；新表统一 snake_case |
| 2 | `User` 表名带引号 | 代码中固定 `pgTable('User', ...)`，勿建同名普通表 |
| 3 | `learned_count` 与 `last_word_rank` 冗余 | 顺序学习下二者相等；保留字段便于未来乱序/复习扩展 |
| 4 | 音频域名未定 | 通过 `NEXT_PUBLIC_AUDIO_BASE` 配置化，改环境变量即可 |
| 5 | 弹窗内 Server Action 报错体验 | 统一 try/catch 返回字符串，弹窗内联展示 |
| 6 | 学习页若每本 > 200 词 | 后续可加分页/虚拟滚动（当前教材量级无此问题） |
