# H5 学英语单词项目 · 需求文档（PRD）

> 项目代号：danci-h5
> 版本：v1.0
> 日期：2026-08-31
> 技术栈：Next.js（App Router）+ TypeScript + TailwindCSS + NextAuth（Credentials）+ Drizzle ORM + PostgreSQL（Supabase）

---

## 1. 项目概述

### 1.1 背景
基于现有 `nextjs-typescript-starter` 模板，开发一个**手机端 H5 背单词应用**。单词数据来源于 `danci-admin` 后台清洗整理后的教材单词 JSON（如 `PEPXiaoXue3_1.json`、`PEPXiaoXue6_1.json`），按「单词书」组织，每本单词书对应一个教材单元/年级。

### 1.2 目标
- 用户在手机浏览器上即可浏览单词书、学习单词；
- 记录每个用户的学习进度，支持「继续学习」；
- 界面简单、专注，单词卡片只展示核心信息，详情页承载完整学习内容。

### 1.3 范围
| 模块 | 说明 |
| --- | --- |
| 全局导航 | 底部 2 个 Tab：首页、我的 |
| 首页 | 已登录展示「最近学习」+ 单词书列表；未登录仅展示单词书列表 |
| 登录/注册 | 弹窗形式，邮箱 + 密码，复用现有 auth 逻辑 |
| 我的 | 用户邮箱、学习进度、退出登录 |
| 单词学习 | 卡片流，从最近学习的下一个单词开始，点击「下一个」切换 |
| 单词详情 | 渲染单词 JSON `content` 字段的完整内容 |

### 3.4 单词学习页（卡片流）

进入方式：
- 首页「继续学习」→ 从该书记录的 `lastWordRank + 1` 开始；
- 首页点击单词书 → 从第 1 个单词开始（若该书已有进度则从 `lastWordRank + 1` 开始）。

```
┌──────────────────────────┐
│  ← 三年级上    12 / 52   │  ← 返回 + 进度指示
├──────────────────────────┤
│                          │
│    ┌────────────────┐    │
│    │                │    │
│    │     ruler      │    │
│    │   /'ruːlə/     │    │
│    │    尺子         │    │
│    │                │    │
│    └────────────────┘    │  ← 整卡可点击 → 详情页
│                          │
│  例句                     │
│  "a 12-inch ruler"       │
│   一把12英寸的尺子          │
│                          │
│  ┌────────────────────┐  │
│  │     下一个   →      │  │
│  └────────────────────┘  │
│                          │
├──────────────────────────┤
│   🏠 首页      👤 我的    │
└──────────────────────────┘
```

**需求点：**
- **卡片字段（尽量简单）**：单词 `headWord`、音标（`ukphone`/`usphone`）、中文释义（`trans[0].tranCn`）、**一个示例例句**（取 `sentence.sentences[0]`，若不存在则取 `trans[0].tranOther` 或隐藏该行）；
- 点击「下一个」→ 切换到本单词书下一个单词，并**自动记录学习进度**（更新 `lastWordRank` 与已学数）；
- 卡片整体可点击 → 进入该单词的**详情页**；
- 顶部显示：返回按钮 + 书名 + 当前序号/总数（如 `12 / 52`）；
- 学完最后一词 → 提示「本书已学完」，可返回首页。

```
┌──────────────────────────┐
│  ← 返回      ruler        │
├──────────────────────────┤
│  ruler                   │
│  /'ruːlə/   /'rulɚ/      │  ← 英音/美音 + 发音按钮
│  🔊 🔊                   │
│  尺子                     │
│  英释：a long flat ...    │
│                          │
│  ── 例句 ──              │
│  • a 12-inch ruler       │
│    一把12英寸的尺子        │
│                          │
│  ── 短语 ──              │
│  • blue pencil 蓝铅笔     │
│  • pencil case 文具盒     │
│  ...                     │
│                          │
│  ── 同近词 ──            │
│  governor / dominator    │
│                          │
│  ── 同根词 ──            │
│  ruling 统治的；主要的     │
│  rule 统治；规则          │
│                          │
│  ── 记忆方法 ──          │
│  没有规矩(rule)，不成方圆… │
└──────────────────────────┘
```

**需求点：** 渲染单词 JSON `content.word.content` 的全部字段：
| 区块 | 数据来源 | 说明 |
| --- | --- | --- |
| 单词/音标/发音 | `wordHead`、`ukphone`/`usphone`、`ukspeech`/`usspeech` | 发音按钮播放音频（拼接音频域名 + speech 值） |
| 释义 | `trans[]` | `tranCn` 中释 + `tranOther` 英释 |
| 例句 | `sentence.sentences[]` | 全部例句（英文 + 中文） |
| 短语 | `phrase.phrases[]` | `pContent` + `pCn` |
| 同近词 | `syno.synos[]` | `hwds` 词列表 + `tran` |
| 同根词 | `relWord.rels[]` | 按 `pos` 分组，`hwd` + `tran` |
| 记忆方法 | `remMethod.val` | 展示文案 |

## 4. 数据结构设计

### 4.1 单词 JSON 结构（已有数据，只读）
来源：`danci-admin/temp/PEPXiaoXue3_1.json`（每行一个单词对象）：

```json
{
  "wordRank": 1,                    // 序号
  "headWord": "ruler",              // 单词
  "bookId": "PEPXiaoXue3_1",        // 所属单词书
  "content": {
    "word": {
      "wordHead": "ruler",
      "wordId": "PEPXiaoXue3_1_1",
      "content": {
        "sentence": { "sentences": [{ "sContent": "a 12-inch ruler", "sCn": "一把12英寸的尺子" }], "desc": "例句" },
        "usphone": "'rulɚ",
        "ukphone": "'ruːlə",
        "ukspeech": "ruler&type=1",
        "usspeech": "ruler&type=2",
        "trans": [{ "tranCn": "尺子", "descOther": "英释", "descCn": "中释", "tranOther": "a long flat..." }],
        "phrase": { "phrases": [{ "pContent": "...", "pCn": "..." }], "desc": "短语" },
        "syno": { "synos": [{ "pos": "n", "tran": "...", "hwds": [{ "w": "governor" }] }], "desc": "同近" },
        "relWord": { "rels": [{ "pos": "adj", "words": [{ "hwd": "ruling", "tran": "..." }] }], "desc": "同根" },
        "remMethod": { "val": "记忆方法文案", "desc": "记忆" }
      }
    }
  }
}
```

### 4.2 单词书（books 表，已有）
字段参考 `danci-admin/db/schema.ts`：`id`、`title`、`wordCount`、`coverUrl`、`bookId`（唯一）、`tags`。

### 4.3 新增：学习进度表 `learning_progress`（建议）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | serial PK | 主键 |
| `userId` | integer | 关联 User.id |
| `bookId` | text | 单词书 id |
| `learnedCount` | integer | 该书已学单词数 |

- 唯一约束：`(userId, bookId)`；
- 用于：首页「最近学习」（按 `updatedAt` 取最近一本）、我的页进度条、学习页起始位置（`lastWordRank + 1`）。

## 6. 关键流程

### 6.1 未登录 → 学习
```
点击单词书 → 切换「我的」Tab → 弹出登录弹窗
  → 登录成功 → 回到首页 → 再次点击单词书 → 进入学习页（从第 1 词开始）
```

### 6.2 已登录 → 继续学习
```
首页「最近学习」→ 点击「继续学习」
  → 学习页从 lastWordRank + 1 的词开始
  → 点击「下一个」→ 切换单词 + POST /api/progress 保存进度
```

## 7. 非功能需求

1. **移动端适配**：以手机浏览器为第一目标（`viewport`、安全区、触摸友好按钮 ≥ 44px）；
2. **底部 Tab 固定**：不随内容滚动；
3. **性能**：单词列表接口一次返回（每本书 ≤ 200 词），前端本地缓存；学习页切换无网络请求（纯前端切词）；
4. **进度实时保存**：切词即保存，防丢失；
5. **安全**：密码哈希（bcrypt）与登录校验沿用现有实现；学习进度接口需校验登录态；
6. **空状态**：最近学习无数据不展示模块；我的页面无进度时显示占位文案。
